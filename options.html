When to stash

When unchecked, each Firefox tab group is capped separately: a group is only stashed down to the minimum tab count on its own, and ungrouped tabs are counted per window as usual.

Due to API limitations, tabs in inactive Zen spaces cannot be counted or stashed, so the tab count is always applied per space.

Never stash

One pattern per line. A tab is kept if its URL contains the pattern anywhere (case insensitive). Use * as a wildcard.

Storage (Tab Stash compatible)

Stashed tabs are saved as bookmarks in the same "Tab Stash" folder used by the Tab Stash extension, in "saved-…" groups it recognizes.
